# Predicting Gene Expression from Promoter Motif Composition

Bioinformatics project for modeling RNA-seq gene expression using promoter motif features derived from HOCOMOCO motifs and SARUS scanning.

## Main components

- Promoter extraction
- Motif scanning
- Promoter × motif matrix construction
- Regression modeling
- Expression prediction evaluation

## Methods

- SARUS motif scanning
- Ridge regression
- Elastic net
- Linear regression

## Data

- HEK293 RNA-seq TPM values
- HOCOMOCOv13 motifs
- Human promoter regions
